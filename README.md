# Personal Portfolio Assignment

Responsive personal portfolio website built with HTML5 and CSS3 only.

## Files

- `index.html`
- `style.css`
- `project-details.html`
- `assets/assets/`
- `screenshots/desktop-portfolio.png`
- `screenshots/mobile-portfolio.png`

## Test Checklist

- Website loads successfully through a local web server.
- Home, About, Skills, Projects, and Contact links navigate to their sections.
- Six skills and two project cards are displayed.
- Contact fields use appropriate input types and `required` validation.
- Project detail links open their matching detail sections.
- Desktop and mobile layouts were visually checked.
- No JavaScript is used.
